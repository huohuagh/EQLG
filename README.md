# EQLG

Official research implementation of **Entropy-normalized Quasi-Laplacian Gravity Centrality (EQLG)** for influential-node identification in complex networks.

This repository provides the source code, experimental functions, parameter settings, and dataset information associated with the manuscript:

**Identifying influential nodes in complex networks with entropy-normalized quasi-Laplacian gravity centrality**

## Overview

EQLG is a structural centrality method for identifying influential nodes in static, undirected, and unweighted complex networks.

The method integrates three complementary components:

1. **Quasi-Laplacian structural energy**, which characterizes the local structural strength of a node and its neighborhood.
2. **Normalized neighborhood degree-share evenness**, which describes how structural support is distributed among neighboring nodes.
3. **Radius-limited gravitational interaction**, which aggregates distance-decayed interactions within a finite topological range.

The entropy term is used to modulate the quasi-Laplacian structural mass. The resulting mass is subsequently incorporated into a radius-limited gravity model to obtain the final EQLG score.

The default truncation radius used in the main experiments is:

```text
r = 3
```

## Source Code

### `src/eqlg.py`

Contains the core implementation of EQLG, including:

- quasi-Laplacian structural energy;
- normalized neighborhood degree-share evenness;
- entropy-modulated quasi-Laplacian mass;
- radius-limited breadth-first search;
- EQLG score calculation.

### `src/sir.py`

Contains the SIR spreading model used to estimate node spreading influence.

The experimental setting uses:

- recovery probability: `gamma = 1`;
- five infection probabilities around the epidemic threshold;
- 1000 independent simulations for each initially infected source node.

The infection probabilities are:

```text
0.8 × beta_c
0.9 × beta_c
1.0 × beta_c
1.1 × beta_c
1.2 × beta_c
```

where `beta_c` denotes the epidemic threshold of the corresponding network.

### `src/metrics.py`

Contains the three evaluation metrics used in the study:

- Kendall rank correlation;
- Jaccard similarity;
- monotonicity.

Kendall correlation evaluates the agreement between the ranking generated by a centrality method and the SIR-based spreading ranking.

Jaccard similarity evaluates the overlap between the top 20% influential nodes identified by a centrality method and those identified by SIR.

Monotonicity evaluates the discrimination capability of a centrality method by measuring the extent of tied scores.

## Experimental Functions

The `experiments/` directory provides research functions corresponding to the major experimental analyses.

### `main_experiment.py`

Provides the main experimental procedure for evaluating EQLG and baseline centrality rankings against SIR-based spreading influence.

The evaluation includes Kendall correlation, Jaccard similarity, and monotonicity.

### `radius_sensitivity.py`

Provides sensitivity analysis for different truncation radii:

```text
r = 1, 2, 3, 4
```

The analysis is used to examine how the truncation radius affects ranking accuracy, influential-node identification, and discrimination capability.

### `runtime_test.py`

Provides wall-clock runtime evaluation functions for EQLG and baseline centrality methods.

It also provides functions for examining how the execution time of EQLG changes under different truncation radii.

### `scalability_test.py`

Provides functions for evaluating the computational behavior of EQLG as network size increases.

The analysis records network size, runtime, and Python-level peak traced memory.

Dataset paths, local file structures, and environment-specific execution procedures are intentionally not fixed in these modules because computing environments and dataset storage configurations may differ across users.

## Experimental Parameters

The main parameter settings are recorded in:

```text
config/parameters.yaml
```

The principal experimental settings are:

| Parameter | Setting |
|---|---|
| Default EQLG radius | `r = 3` |
| Radius sensitivity | `r = 1, 2, 3, 4` |
| SIR recovery probability | `gamma = 1.0` |
| Infection probabilities | `0.8 beta_c`, `0.9 beta_c`, `1.0 beta_c`, `1.1 beta_c`, `1.2 beta_c` |
| SIR simulations per source | `1000` |
| Jaccard top-node fraction | `20%` |

The epidemic threshold is calculated separately for each network according to its degree distribution.

## Datasets

Eight real-world networks are considered in the study.

| Dataset | Nodes | Edges |
|---|---:|---:|
| Dolphins | 62 | 159 |
| Email | 1133 | 5451 |
| NS | 379 | 914 |
| Power | 4941 | 6594 |
| Router | 5022 | 6258 |
| Euroroad | 1174 | 1417 |
| Wikivote | 889 | 2914 |
| Yeast | 1870 | 2277 |

The selected networks cover social, communication, infrastructure, biological, transportation, and scientific collaboration systems.

For consistency among different centrality methods, all networks are represented as:

- static networks;
- undirected networks;
- unweighted networks.

Raw datasets are not redistributed in this repository.

Dataset sources and preprocessing information are provided in:

```text
data/README.md
```

The network data are publicly available from sources including:

- Network Repository: https://networkrepository.com/
- Stanford Network Analysis Project (SNAP): https://snap.stanford.edu/data/

## Baseline Methods

The experimental comparison considers nine representative baseline centrality methods together with EQLG.

| Abbreviation | Method |
|---|---|
| DC | Degree Centrality |
| KC | K-core Centrality |
| BC | Betweenness Centrality |
| PR | PageRank |
| ILC | Improved Laplacian Centrality |
| GLC | Global-Local Centrality |
| MSIS | Multi-Scale Influence Spread |
| KSGC | K-shell-based Gravity Centrality |
| WDKS | Intrinsic- and extrinsic-centrality-based method |

The baseline methods cover local, hierarchical, path-based, recursive, Laplacian-energy-based, multi-scale, local-global, and gravity-based strategies.

Baseline scores can be supplied to the experimental functions according to the formulations described in the corresponding original publications.
